STEP 1 / 3

LINEの準備をしましょう

このページでやること：
✅ LINE公式アカウントを用意する
✅ 2つの「合言葉」をメモする
⏱️ 所要時間：約15分

難しそうに見えますが、
順番通りに進めるだけで大丈夫です😊
わからなくなったら下の「困ったときは」を押してください。

まず確認

まず確認してください

「LINE公式アカウント」とは、お店専用のLINEアカウントのことです。 普段使っている個人のLINEとは別物です。

アカウント開設

LINE公式アカウントを作る

無料で作れます。5分でできます。

①　開設ページを開く

下のボタンを押すと、LINE公式アカウントの登録ページが開きます。

📱 LINE公式アカウントを開設する →
⚠️ ここで注意！
「LINE」で検索して出てくる個人用のLINEアプリではありません。 必ず上のボタンから進んでください。

②　アカウントの種類を選ぶ

登録画面でアカウントの種類を選ぶ画面が出ます。 「未認証アカウント」を選んでください。

アカウントの種類を選択
✅ 未認証アカウント（推奨）
無料・審査なし・すぐ始められる
□ 認証済みアカウント
審査あり・有料
✅「未認証アカウント」を選んでください

③　必要情報を入力する

以下の情報を入力してください。

入力項目
  • ✏️ アカウント名 → お店の名前を入力
  • ✏️ 業種 → お店の種類を選ぶ
  • ✏️ メールアドレス → 連絡先メール
合言葉の取得

2つの「合言葉」を取得する

スマート予約ProとLINEを繋ぐために、2つの合言葉（パスワードのようなもの）が必要です。 コピー&ペーストするだけなので難しくありません。

📋 これから取得するもの：
① 合言葉１：「Channel Secret」
② 合言葉２：「Channel Access Token」
→ 両方とも無料で取得できます
合言葉１の取得

合言葉１（Channel Secret）を取得する

①　LINE Developersを開く

下のボタンを押してください。LINE公式アカウントを作ったときと同じメールアドレス・パスワードでログインしてください。

🔗 LINE Developers を開く →

②　プロバイダーを選ぶ

ログインすると下のような画面が出ます。お店の名前が書いてある部分をクリックしてください。

LINE Developers
Providers
📁 あなたのお店の名前　←クリック！

③　チャネルを選ぶ

お店の名前をクリックすると下のような画面が出ます。「Messaging API」と書かれた部分をクリックしてください。

あなたのお店の名前
📱 Messaging API　← クリック！
あなたのお店の名前
⚠️ この画面が出ない場合
「Messaging API」が有効になっていない可能性があります。
① LINE Official Account Manager を開く → https://manager.line.biz/
② 設定 → Messaging API をクリック
③「Messaging APIを利用する」ボタンを押す
④ もう一度 LINE Developers に戻って確認

④　合言葉１をコピーする

「チャネル基本設定」タブを開くと下のような画面が出ます。 「Channel Secret」の右にある「コピー」ボタンを押してください。

④ 再度 LINE Developers を開く
LINE公式アカウントを作ったときのメールアドレス・パスワードでログインしてください。 個人のLINEアカウントとは別です。
ページを少し下にスクロールしてください。 「チャネルアクセストークン（長期）」という項目の中にあります。
